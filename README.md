# Delta Force — Reverse Engineering

Материалы исследования Android Delta Force: устройство классов, рефлексия, координаты игроков, камера и сохранённые проверки.

**Актуально для последней версии игры по состоянию на 9 октября 2026 года.**

В репозитории только документация и результаты анализа. APK, GUI, loader, исполняемые файлы и исходный код инструментов исключены.

## Статус на 9 октября 2026

Восстановление координат проверено при переходе PID24536 → PID21490. Постоянство ключа для всех запусков не установлено. В последней серии арифметика композиции трансформов совпала с нативным расчётом в 640 проверках. Полный мировой трансформ удалённых Mesh и мировые координаты костей независимо не подтверждены.

Документы сохраняют историю исследования: старые выводы могут быть уточнены новыми проверками. Числа из внешних дампов проверяются для конкретной сборки отдельно; совпадение названия поля не доказывает совместимость.

## Сырые данные

Снимки памяти `.bin` вынесены в архив `reverse-memory-data.tar.gz` в GitHub Release. Для восстановления структуры распаковать архив из корня репозитория:

```sh
tar -xzf reverse-memory-data.tar.gz
```

SHA-256 файлов перечислены в `docs/MANIFEST.json`, сумма архива — в `docs/RELEASE_SHA256SUMS`. Игровые APK и библиотеки в архив не включены.
